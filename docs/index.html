이름을 정리하는 작은 작업대

파일명은 가지런하게.
원본은 그대로.

치환·날짜·일련번호를 조합하고 충돌을 확인하세요. 새 이름의 복사본 ZIP과 매핑표를 만듭니다.

01파일 가져오기

파일명 목록만 붙여넣기

한 줄에 하나. 목록 모드에서는 CSV만 저장합니다.

02이름 규칙

순서: 본문 치환 → 앞·뒤 글자 → 날짜 → 번호 → 확장자. 마지막 점 뒤를 확장자로 취급합니다. 선택 순서로 번호를 붙입니다.

03결과 미리보기

원본 이름새 이름 / 상태

ZIP은 압축 없이 묶습니다. 파일 내용은 유지하고 이름만 바꿉니다. 날짜·권한 등 메타데이터는 보존하지 않습니다.

사용 범위와 참고 자료

파일은 브라우저 안에서만 처리합니다. 서버 전송·원본 변경·자동 저장은 없습니다. 폴더 계층 없이 ZIP 최상위에 담습니다. Windows 금지 문자·예약 이름과 UTF-8 255바이트 상한을 검사합니다. 대소문자와 NFC 정규화가 같은 이름도 충돌로 차단합니다. 전체 경로 제약은 기기마다 다릅니다.

CSV는 UTF-8 BOM 형식이며 수식 시작 문자 앞에 작은따옴표를 붙입니다. ZIP 이름은 원문입니다.
