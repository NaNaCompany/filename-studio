使用范围与参考资料

文件仅在浏览器内处理，不上传、不修改原件、不自动保存。文件放入 ZIP 根目录，不保留文件夹层级。检查 Windows 保留名称、禁用字符以及 UTF-8 255 字节上限。忽略大小写及 NFC 规范化后相同的名称也视为冲突。完整路径限制因设备而异。

CSV 使用 UTF-8 BOM，对可能作为公式解释的值添加前导单引号。ZIP 文件名保留原文。
