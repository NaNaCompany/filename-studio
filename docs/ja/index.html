名前を整える小さな作業台

ファイル名を整然と。
元のファイルはそのまま。

置換・日付・連番を組み合わせ、重複を確認。新しい名前のコピーを ZIP と対応表で保存します。

01ファイルの取り込み

ファイル名だけ貼り付け

1行に1つ。このモードでは CSV のみ保存できます。

02名前のルール

順序：本体の置換 → 接頭辞・接尾辞 → 日付 → 番号 → 拡張子。最後の点以降を拡張子とします。選択順で連番を付けます。

03結果プレビュー

元の名前新しい名前 / 状態

ZIP は無圧縮です。内容は変更しません。日時・権限などのメタデータは保持しません。

使用範囲と参考資料

ファイルはブラウザー内で処理します。アップロード・元ファイルの変更・自動保存は行いません。フォルダー階層は保持せず ZIP の直下に配置します。Windows の禁止文字・予約名と UTF-8 255バイトの上限を検査します。大文字小文字と NFC 正規化で同じ名前も重複と判定します。パス全体の制限は環境により異なります。

CSV は UTF-8 BOM 形式です。数式として解釈される可能性のある値に単一引用符を付けます。ZIP の名前は原文のままです。
