ZIP uses no compression. File contents are unchanged. Timestamps, permissions and other metadata are not preserved.

Scope and sources

Files stay in your browser. No uploads, original changes or automatic saving. Files are placed at ZIP root without folders. Checks cover Windows reserved names, forbidden characters and a 255-byte UTF-8 limit. Case-insensitive and NFC-equivalent names are treated as collisions. Full path limits depend on your device.

CSV uses UTF-8 BOM and prefixes formula-like values with an apostrophe. ZIP filenames retain their exact text.
